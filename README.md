# CSE 241 - Object Oriented Programming (C++)

Gebze Technical University | Department of Computer Engineering

Laboratory problem sets and homework implementations covering core and advanced Object-Oriented Programming (OOP) concepts in Modern C++.

---

## Topics & Problem Sets

- **`PS01/`**: Number manipulation, random simulation, and game logic basics.
- **`PS02/`**: Control flow, modular design, and probability modeling.
- **`PS03/`**: Class encapsulation, member methods, and state tracking (`HotDogStand` class).
- **`PS04/`**: Dynamic arrays, STL vector mechanics, and memory allocation.
- **`PS05/`**: String manipulation, object references, and data parsing.
- **`PS06/`**: Multi-file architecture, namespace separation, and modular authentication (`Authenticate` module).
- **`PS08/`**: Standard Template Library (STL) algorithms, iterators, and container manipulation.
- **`PS10/`**: Template programming, generic programming, and dynamic data structures.
- **`PS11/`**: Robust exception handling (`try-catch-throw`), custom exception types, and runtime invariants.

---

## Compilation

Source files are written in modern C++ (C++14/C++17):
```bash
g++ -std=c++17 -Wall -Wextra main.cpp -o app
./app
```
